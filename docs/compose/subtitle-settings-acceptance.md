# 字幕外观设置验收

日期：2026-10-03。项目：`D:\bilive`。

## 实际问题

用户截图中的片段已保存 30 行字幕，字幕版本与成片版本均为 2，且成片有效。读取实际 ASS 与成片第 5.5 秒确认字幕已经烧入视频：底部有“雪狐的C盘现在还剩下216”。原样式字号为 20、底部边距为 60，在网页缩小播放时很小且接近控制条。本轮对照帧使用字号 48、边距 110、描边 2，文字清晰可见。

诊断帧保存在 `.runtime/subtitle-diagnosis/`，没有重写已批准、已上传的实际成片。

## 实现

- 设置 → 字幕默认样式加入可编辑的字体、字号、上下边距、九种位置、描边宽度、文字颜色、描边颜色及缩放预览。
- “使用清晰预设”填入字号 48、边距 110、底部居中、描边 2、白字黑边；用户点击保存后生效。“恢复已保存设置”撤回表单草稿。
- 后端校验样式并原子保存当前工作台配置文件的 `[edit]` 表，保留其他配置内容。修正顶层 edit 与旧 slice.subtitle 字段的优先级。
- 新建人工片段、新分析片段在创建时读取持久化默认样式，主播档案的单独覆盖继续优先。正在运行的 Worker 使用新代码后无需重启即可读取后续设置变化。
- 录播库 → 内容 / 投稿资料 → 当前片段字幕样式加入设置页链接及“应用默认样式并使旧成片失效”。应用使用现有版本检查和样式保存路径，保留字幕内容，撤回未批准的旧成片暂存，需要重新生成成片。
- 已批准发布、后台任务与未保存草稿保护继续适用，没有添加覆盖已上传成片的入口。
