# 人工审核与成片阶段验收

日期：2026-10-01。范围：D:\bilive 新版隔离开发；未使用旧生产媒体、队列或凭据，未执行真实投稿。

## 已实现

- 录播库读取配置根内的 MP4，按场次查询持久化片段；人工补片记录源路径、入出点、标题和依据。同源同区间复用身份，改范围保留身份并增加版本。
- 源与当前成片可播放，媒体接口支持 Range。缺源或越界拒绝；旧成片失效后拒绝预览，残留文件不能恢复有效状态。
- 字幕行按片段相对秒编辑；草稿按场次/片段保存在浏览器，刷新可恢复。服务端保存检查版本，失败保留草稿。
- finalize/render/reburn 使用统一人工成片路径；API 只写任务，Worker 执行精确裁剪和字幕烧录。Worker 使用持久片段数据，不信任请求里的任意源路径/区间。
- 当前版本成片暂存 staged，人工批准由 Worker 激活到 queued。旧的直接 stage/activate/withdraw API 返回 410，避免绕过成片版本校验。
- 字幕/范围编辑原子撤回 staged 行；已批准或受保护队列行不允许覆盖。旧媒体保留，当前引用失效。
- 裁剪工件与源范围绑定；改范围重新裁剪，后续烧录失败保留原始裁剪与编辑，重试复用裁剪。
- 动作提交和领取使用跨进程锁；同目标冲突动作拒绝，相同载荷复用活跃任务。锁由操作系统管理，进程退出释放锁。
- 发布页仅展示实际队列和 unavailable/空状态，不再以演示数据填充真实队列。
