## 投稿类型修正（2026-10-07）

- 上文的转载来源修复是当时的实现记录；其中默认按转载投稿不符合本项目的剪辑投稿用途，现已修正。
- 根因：Web 投稿适配器将缺省 `copyright` 设为 `2`（转载），上传消费者未显式设置投稿类型。
- 上传消费者现明确提交 `copyright=1`（自制），适配器缺省也为自制。自制请求的 `source` 为空，录播来源仍保留在已有简介中。显式转载调用仍需提供来源，其他投稿类型拒绝。
- 不重写已发布稿件、不激活 staged 或 failed 队列、不通过真实投稿验证。已批准但尚未投稿的队列在下次消费时使用自制类型，无需重新生成成片。
