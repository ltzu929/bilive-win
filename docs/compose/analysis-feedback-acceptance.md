# 录播 AI 分析状态反馈（2026-10-05）

录播页在播放器上方持续显示整场分析状态。点击后立即显示正在提交，提交成功显示排队；Worker 领取后显示正在分析、已用时间与持久化候选计数。每两秒只读查询任务及分析证据，查询失败会显示错误并继续查询。候选计数不是预估百分比。

结束结果区分未召回候选、全部明确建议丢弃、可审核片段、候选判断异常和字幕 / 成片阶段失败。未召回只说明弹幕召回没有候选，不能写成 AI 看完整场并认定没有内容。跳过和取消也有独立提示。

轮询期间不重建播放器或编辑区。结束时没有编辑草稿才自动加载结果；存在字幕、样式、投稿资料、人工源范围草稿或打开的对话框时，保留编辑并提示保存后刷新。切换页面或场次会停止旧查询更新。

## 字幕识别空白行修复

用户随后反馈 `subtitle text empty`。手动字幕识别将模型返回的空白 cue 直接转换成字幕行，整次任务因此失败；正式自动字幕入口同样会将空白 cue 判为异常。两个入口现均跳过空白行，保留有效文本及原时间；全为空时给出中文提示，不覆盖已保存字幕。辅助识别中的空白行也不再让有效转写失去复用资格。

- 自动分析的技术失败记录新增已脱敏具体错误，证据面板可展示详情。
