# 文档

这个项目自用，文档只分三类。

| 文件夹 | 用途 | 常用入口 |
|---|---|---|
| `usage/` | 怎么启动、配置、审核、发布和清理 | [使用说明](usage/README.md) |
| `development/` | 开发时查实现、约定和后续方向 | [项目说明](development/project.md)、[优化计划](development/optimization.md) |
| `history/` | 需要时追溯过去的验收和问题调查 | [历史记录](history/README.md) |

平时看使用说明，继续开发看项目说明与优化计划。历史记录中的日期、开关、进程和测试结果只说明当时的情况，不作为当前运行说明。

## 已清理的过期内容

初期规格空勾选表、累积开发跟踪、第一版页面 QA 和设计草案已合并或替换；18 张旧页面/调试截图已移除。原 `compose/`、`design/` 目录不再保留。仍有效的产品判断、保护规则、研究方向和专题验收证据已整理进上述三类，旧版本可从 Git 查回。

以后更新已有对应文档；只有需要保留独立验证证据时才增加历史记录，不再为每轮开发重复创建“当前状态”说明。
