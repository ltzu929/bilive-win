# 手动分析与废弃片段验收（2026-10-04）

> 历史记录：仅说明文中日期与验证范围，旧运行快照和阶段待办不代表当前状态。当前说明见 [文档导航](../README.md)。

开发期间默认关闭自动 AI 切片。用户从录播库选择场次，点击“AI 分析本场录播”才主动提交本场分析。设置 → 处理参数新增“录制结束后自动 AI 切片”，需要勾选并保存才开启。

- `AnalysisConfig.auto_start` 默认 false，本机配置显式 false。录制完成仍进行本地 FLV → 验证 MP4 → 删除 FLV；默认不提交分析。
- 开关持久化到配置文件；已有 Worker 每次转码后重新读取。开启仅影响之后完成的录播，保存不唤醒 Worker、不补发历史场次。发布继续需要人工批准。
- 自动任务带独立标识；关闭会取消 pending 自动分析，手动任务保留。执行自动分析前复查开关；已经开始的分析完成当前任务。
- 候选下方提供“废弃当前片段”，字幕页也可直接使用。原因选填，默认“人工判断无需切片”。撤回未批准 staged 成片、使当前成片失效，保留源视频、历史工件与废弃依据。
- 废弃状态刷新后保留，候选和编辑区显示“已废弃”；编辑、重新判断、字幕识别、成片和发布接口拒绝继续操作。既有已批准发布、活跃任务及整场复核保护继续生效。
