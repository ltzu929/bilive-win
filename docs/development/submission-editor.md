# 视频投稿页

从「录播库 → 03 确认成片 → 去投稿」或「发布队列 → 编辑投稿」打开 `#/submission?segment_id=<片段 ID>`。页面读取一条切片的当前成片、投递资料和封面。「返回成片检查」定位到原场次的同一片段。日常操作见[发布与主播默认](../usage/README.md#发布与主播默认)。

## 草稿与提交

| 操作 | 数据去向 |
|---|---|
| 编辑表单、选择话题、上传封面预览 | 以录播和片段 ID 保存浏览器草稿。页面提示草稿写入失败时，应先保存到项目再离开。 |
| 保存草稿 | 将资料写入当前片段。已有有效成片时同步更新暂存投稿记录。只改标题、简介、标签等资料或更换封面时可以沿用有效视频。 |
| 生成文案建议 | 先保存表单，提交 `generate_metadata`。当前版本须有已保存字幕。任务读取字幕、人工看点、片段音画建议和已采用的主播指导，返回标题、简介及标签。 |
| 采用建议 | 将建议填入当前浏览器草稿，允许继续编辑。点「保存草稿」后持久化。 |
| 提交投稿 | 先保存表单，再按当前片段版本提交 `approve_publish`。后台批准后激活上传队列，页面定位到对应记录。 |

字幕、范围或样式变化会使旧成片失效，仍可先保存投稿资料，重新生成后再提交。草稿版本落后时，页面提示核对当前成片，点「已核对，继续编辑这些资料」后才能保存。已批准或已废弃的片段锁定资料编辑。有片段任务或封面正在加载时，页面会等待它结束。

## 封面选帧与精剪时间

- 投稿预览显示当前成片和剪后时长。点击「从当前画面选帧」时，先把播放进度映射回源录播，再从目标位置及前后 0.5 秒提取范围内的候选帧。没有当前有效成片时可填片内秒数。已有分析建议时可点「看推荐画面」。
- 取帧优先使用源录播，其次使用覆盖该源区间的候选视频，再次是当前有效成片。从精剪成片取帧会跳过已删除的区间。界面显示片内时间，帧以源录播毫秒定位。
- 「下载原图」取得所用视频的原尺寸 PNG。「复制 GPT 提示词」结合选中帧、人工或模型看点、附近字幕和稿件标题整理制图要求。用户在 GPT 网页版生成封面，再上传 JPG、PNG 或 WebP。预览阶段可以更换图片，保存后采用 960 × 540 投稿封面。重新生成成片会沿用已采用的封面设计。

## 投递字段与跟进

标题最多 80 字、简介 2,000 字、粉丝动态 233 字。分区填写数字编号。话题与普通标签合计最多 10 个，每个最多 20 字。保存草稿和批准投稿时都会核对相关选项。标签、动态、话题、合集及小节随片段和队列持久化，投稿重试读取已保存资料。

合集关联发生在投稿取得 BV 之后。加入失败时可以在发布历史中单独重试。话题及活动的实际收录由创作中心和活动规则决定。更多平台选项的原始调查见 [B 站投稿页调查](bilibili-submission-rea-20261017.md)。
